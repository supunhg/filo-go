### 6. Memory Forensics
**Like Volatility, but Go-native**

```go
memory := filo.ParseMemory("memory.dmp")

// Extract processes
for _, proc := range memory.Processes {
    fmt.Printf("PID: %d Name: %s\n", proc.PID, proc.Name)
    
    // Extract network connections
    for _, conn := range proc.Connections {
        fmt.Printf("  %s:%d -> %s:%d\n", conn.LocalIP, conn.LocalPort, 
                    conn.RemoteIP, conn.RemotePort)
    }
    
    // Extract injected code
    for _, region := range proc.MemoryRegions {
        if region.IsSuspicious() {
            data := region.Dump()
            filo.Analyze(data)
        }
    }
}
```

**Why it's great:**
- Go-native = faster than Volatility
- Single binary deployment
- Better memory efficiency

### 12. Evidence Tamper Detection
**Blockchain-verified integrity**

```go
// Hash and store on blockchain
chain := filo.NewEvidenceChain(&ChainOptions{
    Blockchain: "ethereum",
    Network:    "mainnet",
})

// Store evidence hash
txHash := chain.Store(&Evidence{
    Path:      "/evidence/malware.exe",
    SHA256:    "abc123...",
    Timestamp: time.Now(),
    Examiner:  "john.doe",
})

// Later: verify integrity
valid := chain.Verify("/evidence/malware.exe")
// true = not tampered, false = modified
```
